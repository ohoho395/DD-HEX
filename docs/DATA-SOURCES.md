# DD HEX 数据来源

本包使用 AramHex 基线提交 5b5d37d 随附的 16.22 版快照。实际统计文件及口径见 lolhex/data/bundled/latest.json 与 meta.json。

| 界面内容 | 来源与口径 |
|---|---|
| 英雄胜率、排名、英雄搭配海克斯的胜率、召唤师技能组合 | czgreat/aramhex-data 的国服七区样本。截至北京时间 2026-11-06 12:02:35，共采集 4,281,885 场，按队列 2400、至少 240 秒、10 人完整且 5 胜 5 负等条件筛出 4,145,668 场。海克斯按终局持有统计。本期没有分段数据。 |
| 命运之武器装备参考 | 同一项目从持有该海克斯的对局整理。使用至少 300 秒的对局，以记录位置近似装备顺序，在最多三个高使用候选中比较胜率。 |
| 出门装、鞋、核心三件及技能加点 | 腾讯官方公开资料的本地快照，版本 16.22，资料日期 2026-11-05。上游筛选排序并移除基础鞋。本期完整六件套、搭档和腾讯海克斯评级未提供。 |
| 名称、说明、图标、头像及外服译名 | 主要为腾讯 game.gtimg.cn 和 mlol.qt.qq.com 等公开资源。部分中文名、外服文本和客户端头像由 CommunityDragon 补全，多语言英雄名取自 Riot Data Dragon。 |
| 别名和 OCR 纠错 | 英雄别名整理自 Hexdata。外号和识别纠错表由上游整理。 |
| 当前卡片与首选 | 本机截屏经 RapidOCR 识别，与本地数据匹配。DD HEX 结合胜率、场次与平滑参数计算首选，保留样本不足提示。 |

默认离线使用快照。主动开启统计更新后，读取 https://raw.githubusercontent.com/czgreat/aramhex-data/main 并核验 SHA-256。DD HEX 不从你的游戏内存、客户端接口或对局记录采集胜率。公开导出资料能核实统计口径，无法据此确认每场原始记录的具体采集接口。
